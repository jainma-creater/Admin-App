We have built a **Branch Visit Inspection System** to replace paper-based branch inspections, and it is ready to go live.

**How it works:**
- **Field staff** use a mobile app: they visit a branch, complete a checklist, and photograph each item as proof — even in low-network areas (photos save on the phone and upload later).
- **Managers** use a web dashboard: live visit status, branch-wise compliance scores, all photo evidence, and approval of completed visits. Branches, users and checklists are managed here too.

**Current status:** Fully built and tested on real phones — app and dashboard both working end to end.

**Go-live plan (AWS cloud):**
1. Move the system to AWS — one small server + secure photo storage, accessed via our own web address (e.g. `branchvisit.yourcompany.com`), with automatic data backup
2. Install the app on staff phones — free for Android (a simple download link); iPhone needs an Apple developer account ($99/year)
3. Pilot with one region, then roll out to all branches

**Running cost:** roughly **₹2,500–4,000/month** for the server, plus the one-time domain and Apple account fees.

**What we no longer depend on:** office PCs or the same Wi-Fi — the system runs entirely in the cloud, usable from anywhere.
